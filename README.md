## 把视频交给 Codex

Codex LightCut（轻剪）通过对话完成口播剪辑，交付可以继续调整的剪映草稿。视频、字幕、音乐和效果保留独立轨道。

## 安装与开始

1. 点击上方对应系统下载，解压安装包。
2. 在 Codex 中打开解压后的 `codex-lightcut` 文件夹，发送：

   > 帮我安装 LightCut，准备本地语音转写，全程后台操作。

3. 安装完成后，把原视频拖给 Codex，发送：

   > 用 LightCut 剪辑这条视频，去掉重复和多余停顿，添加单行字幕，最后给我可编辑的剪映草稿。

4. 根据引导选择封面、画面效果、背景音乐和剪辑节奏。做好后，在剪映首页打开对应草稿，检查并导出。

安装包已包含两端草稿引擎，Codex 会选择对应系统并准备依赖，无需手动寻找引擎或编辑配置文件。首次安装需要网络。详细步骤见[安装与使用](docs/getting-started.md)。

## 按你的风格剪辑

| 设置 | 可以怎样选择 |
| --- | --- |
| 封面 | 使用自己的图片、从视频取帧、生成新封面或不加封面；尺寸可单独指定 |
| 生成风格 | 立体吸睛、极简专业、人物焦点、杂志质感、趣味插画；成图确认后使用 |
| 画面效果 | 使用预设滤镜、调色和美颜，全部关闭，或只修改其中一部分 |
| 背景音乐 | 提供自己有权使用的音乐，或不加音乐；音量单独设置 |
| 字幕与节奏 | 调整字体、字号、位置、单行分句、语速、停顿和片尾渐隐 |
| 默认偏好 | 仅用于本次，或保存为以后默认；随时可以修改 |

例如：

> 美颜轻一点，字幕往上移，其他设置保持不变。

> 这次不加背景音乐，不修改我之前的默认设置。

## 当前版本

- **LightCut：R8.4 / 0.4.4-preview.1**。
- **适配剪映专业版：11.5.0**，支持 macOS（Apple Silicon）和 Windows x64。
- Windows 对应构建：**11.5.0.14471**。
- 后续随剪映版本更新持续适配，新版本通过兼容验证后再支持。

请先安装对应版本的剪映专业版。剪映升级前查看[版本兼容](docs/platforms.md)，避免自动更新后暂时无法生成草稿。

## 常见问题

**会影响我使用电脑吗？** 制作在后台运行，不主动打开、关闭或激活剪映，不模拟键鼠。媒体处理会使用部分计算资源。

**草稿为什么还没出现在首页？** 如果剪映正在运行，登记任务会等待你正常退出；完成后再打开剪映查看。无需强制结束程序。

**能在剪映继续修改吗？** 可以，交付的是可编辑草稿。原素材和已有草稿保留，修改会生成新版本。

**需要 VIP 吗？** 是否需要会员取决于你选择的素材和效果，使用与导出权益以剪映提示为准。

**下载后直接双击就能剪辑吗？** 请把解压后的插件交给 Codex 安装和使用。LightCut 通过对话工作，不是独立的视频编辑窗口。
