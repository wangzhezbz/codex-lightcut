# 功能介绍

[返回首页](../README.md)

- **口播剪辑**：根据表达内容整理重复、准备空白和停顿，可调整普通播放速度。
- **可编辑字幕**：单行分句，调整字体、字号和位置；剪切后重新计算字幕时间并检查接缝。
- **封面**：自有图片、视频取帧或生成图片；独立设置尺寸，成图确认后使用。
- **画面效果**：预设高清增强12%、明暗色彩微调和美颜，三项可独立开启、关闭或调整。
- **声音**：人声、背景音乐独立设置，保留可编辑音轨。
- **片尾**：可选画面渐隐，时长可调整。
- **偏好**：设置仅用于本次，或按你的要求保存默认；以后随时更改。
- **后台制作**：不抢键鼠、不自动打开剪映，完成后交付草稿名称。

LightCut面向口播草稿制作，不覆盖剪映所有功能。云端AI、在线模板和任意VIP特效不属于通用自动化入口。生图需要Codex会话提供相应能力；背景音乐由你提供有权使用的文件。字幕专有名词和最终节奏可在草稿中继续调整。
