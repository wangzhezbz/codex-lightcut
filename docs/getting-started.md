# 安装与使用

[返回首页](../README.md)

## 准备

准备Codex、剪映专业版11.5.0和原始视频。Windows对应构建为11.5.0.14471；macOS使用Apple Silicon，Windows使用x64系统。首次安装保持网络连接。

## 安装

1. [下载安装包](../downloads/LightCut-Mac-Windows-R82.zip)，解压到固定位置。
2. 在Codex中打开`codex-lightcut`文件夹，发送“帮我安装LightCut，并准备本地语音转写”。
3. Codex读取插件说明并选择系统安装入口，自动准备独立环境和包内引擎。完成后再开始剪辑。

不需要手动修改JSON、查找引擎目录或下载效果参考草稿。不要移动已经投入使用的安装目录。

## 剪第一条视频

把视频拖进Codex，说明内容删留要求，例如：

> 保留主要观点，剪掉重复和长停顿，字幕单行，封面帮我生成，最后给我可编辑剪映草稿。

首次会确认四组设置：封面、画面效果、背景音乐、字幕与节奏。生成封面有五种风格可选，展示实际图片后再确认。封面尺寸和正片比例可以分别指定。画面效果可使用预设、关闭或修改部分；音乐可提供自己的文件或不加。

已确认的要求不会重复询问。你可以说“以后都这样”，保存默认；否则设置仅用于本次。新视频会重新处理主题和封面，不套用上一条的标题。

## 查看和修改

制作完成后，Codex会给出草稿名称。你自行打开剪映，在首页找到对应草稿，检查字幕和声音后导出。剪映运行期间，后台登记会等待你正常退出，不会强退程序。

想修改时直接说“字幕提高一点，其他不变”或“这次不用美颜”。保留已有草稿，另建修改版本。

## 升级与问题处理

新版解压到新的程序目录，让Codex升级LightCut并复用现有数据。保留原数据目录和旧程序，确认新版本可用后再自行整理。

安装下载中断时让Codex继续安装即可，正确缓存会复用。剪映版本不匹配时，提供实际版本号让Codex检查，不跳过校验。反馈问题请提供系统、LightCut版本、剪映版本和错误提示，不必公开私人视频或账号信息。
