# 安装与使用

[返回首页](../README.md)

准备好 Codex 和剪映专业版 11.5.0，首次安装保持联网。

## 安装

[下载安装包](../downloads/LightCut-Mac-Windows-R88.zip)，拖给 Codex，说：

> 帮我安装。

## 开始剪辑

把视频拖给 Codex，说：

> 帮我剪辑。

第一次会引导你选择封面、滤镜调色美颜、背景音乐和字幕。可以用推荐设置，也可以按自己的喜好调整。封面可以用自己的图片，也可以从五种风格中选一种生成。

做好后，按提示打开剪映里的草稿，查看并导出。

## 以后怎么用

继续发视频，说“帮我剪辑”即可。想沿用设置就说“以后都这样”，想修改就直接说，例如“美颜轻一点”或“这次换首音乐”。

## 更新

把新版安装包交给 Codex，说“帮我升级，保留原来的设置”。

遇到问题，把提示或截图发给 Codex 即可。
