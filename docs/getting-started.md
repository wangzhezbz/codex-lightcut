## 当前可用内容

这个公开仓库提供项目介绍、平台状态、架构与协作说明。`index.html` 是可以离线打开的展示页面。**目前没有公开可安装的剪辑程序，也没有可从本仓库直接启动的剪辑引擎。**

已经交付的 Mac 草稿来自单独的本地研究环境。Windows 基础试验版也只在本地准备，尚未完成实机验收；它不作为本仓库的公开 Release 分发。

## 准备一份清楚的剪辑要求

下面是未来工作流及现有研究协作可使用的输入示例，不是已经发布的 CLI 命令：

> 请把这段口播整理成可继续编辑的剪映草稿。保留核心观点，去掉重录、明显准备动作和过长停顿；字幕单行，按语义断句；分别保留人声、字幕和背景音乐轨道。使用我确认的字幕位置、音量与效果预设。全程后台处理，不主动打开剪映。遇到不支持的效果请明确报告。

准备原始素材、内容删留要求、画布比例、字幕风格、已获使用权的音乐，以及需要保留可调的效果。不要在公开 Issue 上传私人视频、授权资源或账号数据。

## 本地检查展示仓库

需要 Python 3.11+，不依赖剪映、账号或第三方 Python 包：

```sh
python tools/check_publication.py
```

该命令检查本仓库的链接、SVG、页面及分发范围，不会运行剪辑或加载原生库。
