## 当前可用范围

下载[R8.2完整插件包](../downloads/LightCut-Mac-Windows-R82.zip)，解压后交给Codex读取包内START-HERE.md并执行安装。包内已含Mac/Windows草稿引擎，无需用户另外寻找。剪映11.5.0需自行安装。

## 已有预览用户的流程

1. 告诉 Codex“后台剪辑这条视频”，提供本机原片。Agent 检查环境、复用缓存和已有偏好。
2. 首次选择封面：自有图片、生图、取帧或不加。生图有立体吸睛、极简专业、人物焦点、杂志质感、趣味插画五种起始风格；展示成图后确认。封面尺寸独立于正片比例。
3. 选择预设效果、关闭或修改部分。预设包含高清增强12%、明暗色彩调整和美颜；三项独立选择，以本机实际支持为准。
4. 选择自己有权使用的背景音乐或不加；确定字幕和节奏。设置可仅用于本次，也可按用户要求保存默认，以后随时修改。
5. Agent 转写、剪辑、校正字幕并后台生成草稿。旧视频的主题和封面文件不自动复用到新内容，固定音乐仅在明确授权后保存。
6. 用户方便时自行打开草稿检查。运行中的剪映不会被强退，已有草稿不会覆盖。

已有明确偏好不重复询问，不夹带开发测试选项。不要求普通用户查路径、改 JSON 或制作效果参考草稿。缺少合法引擎或不支持效果时明确说明，不将效果关闭后冒充成功。

## 新用户试用前需要完成

集成引擎已交付。首次环境准备、新素材字幕同步、效果资源和保存重开需在干净机器验证，不能用已有测试机升级成绩代替。

## 检查公开仓库

Python 3.11+ 执行 `python tools/check_publication.py` 检查链接、SVG与分发范围。它不是剪辑命令，不加载原生引擎。不要在公开 Issue 上传私人视频、完整字幕或账号资料。
