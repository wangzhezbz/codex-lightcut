# 平台兼容性

**当前适配剪映专业版 11.5.0；Windows 已验收构建为 11.5.0.14471。后续跟随剪映版本更新持续适配，新版本经验证后再纳入支持。**

[返回首页](../README.md) · 状态日期：2026-09-24

## macOS

匹配的剪映 11.5.0 本机环境已完成真实口播草稿构建、回读和后台登记，既有样片效果得到用户确认。R8.1 字幕映射与接缝检查共用代码已通过 Mac 测试；不把 Windows 新样片验收代替 Mac 新样片验收。

## Windows

剪映 11.5.0.14471 对应固定组件已完成原生构建、回读、登记，滤镜、调色、美颜及封面修正均有用户样片确认。R8 已有环境升级及封面尺寸迁移通过；R8.1 的 44 项检查通过，约 12 秒字幕接缝样片完成用户查看验收。

这些结论限于已测环境。保存退出重开、导出、其他剪映版本和全新电脑零配置仍未据此确认。字幕阴影尚未适配，显式请求时拒绝，不能静默关闭。

## 安装与资源

两端已有私有预览安装入口，准备独立依赖并复用缓存。匹配原生引擎仍须有合法来源；公开仓库不包含受限引擎，也没有完整公开安装包。会员资格与资源使用仍由剪映校验。

## 其他平台与后台约定

面向 macOS/Windows，不承诺 Linux 原生支持。不启动、关闭或激活剪映，不抢键鼠、不自动播放；登记等待自然退出。后台分析仍占用 CPU/GPU、内存与磁盘。
