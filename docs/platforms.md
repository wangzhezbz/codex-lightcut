# 版本兼容

[返回首页](../README.md)

| 项目 | 当前支持 |
| --- | --- |
| LightCut | R8.4 / 0.4.4-preview.1 |
| macOS | Apple Silicon；剪映专业版11.5.0 |
| Windows | x64；剪映专业版11.5.0.14471 |

两端使用同一安装包，安装器自动选择对应引擎。剪映应用需自行安装，其他基础依赖由Codex准备。Linux和Intel Mac暂不列入本包支持范围。

后续随剪映版本更新持续适配，新版本完成兼容验证后再支持。升级剪映前查看本页；遇到组件不匹配，让Codex检查实际安装版本，不要跳过摘要校验。

会员素材与效果的使用和导出权益，以剪映账号和实际提示为准。Windows暂不支持字幕阴影，请选择无阴影字幕。
