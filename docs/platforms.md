# 平台兼容性

[返回首页](../README.md) · 状态日期：2026-09-23

## macOS

**本机流程已验证，尚无通用安装包。**

本地匹配的剪映 11.5.0 环境已完成真实口播草稿的后台构建与登记；指定美颜效果在既有样片中获得过用户确认。新组合效果、其他系统/芯片/剪映版本不能据此视为已验收。画面、字幕和声音仍须以具体草稿检查为准。

支持范围目前是本地固定的应用身份、依赖及资源。以后更换版本需重新校验，不把“版本号相同”视为所有程序组件都相同。

## Windows

**基础适配已编码，原生运行尚待实机验收。**

本地候选参考上游 Windows PR #15，并对安装目录一致性、DLL 身份校验、进程检查失败处理和字符串边界进行了修复。目标是剪映 11.5.0.14471 及对应固定指纹的组件。Mac 宿主模拟检查了参数和草稿结构，没有实际调用 Windows DLL。

待验证：安装身份 → 原生编码/回读 → 新草稿登记 → 打开播放 → 保存 → 退出重开。字幕字体和位置、人声 +15 dB、BGM 0 dB需单项核对。

Windows 美颜、滤镜和调色资源尚未完成适配。基础兼容样片明确无此类效果；完整工程遇到效果缺项应停止并报告，不悄悄省略。

## 其他平台

当前面向 macOS 与 Windows。Linux 剪映原生工作流没有适配计划承诺，也没有对应安装入口。

## 对后台执行的约定

不启动或关闭剪映，不模拟输入，不抢焦点，不自动播放音视频。登记等待编辑器自然退出。媒体解码、分析和编码会占用 CPU/GPU、内存与磁盘；资源限额及低占用体验还需持续实测。
