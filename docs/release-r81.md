## 修复原理与边界

源时间字幕按最终保留区间、实际变速和封面偏移计算。字幕跨剪切边界时要求先按保留字词拆句或重对齐，不复制整句。旧工程增加跨剪切点提示。

数学映射不能纠正粗ASR的时间偏差。此次包含词时间与波形复核，没有声学强制对齐模型；样片通过不代表任意视频自动同步。新素材仍需检查剪切点前后及首尾字幕。
