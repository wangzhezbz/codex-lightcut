# LightCut R8.2

版本：0.4.2-preview.1。

[下载Mac / Windows安装包](../downloads/LightCut-Mac-Windows-R82.zip) · [安装与使用](getting-started.md) · [版本兼容](platforms.md)

安装包已包含两端草稿引擎。解压后在Codex中打开codex-lightcut文件夹，发送“帮我安装LightCut，并准备本地语音转写”。安装完成后提供视频和剪辑要求即可。

当前适配剪映专业版11.5.0，Windows对应构建11.5.0.14471。剪映需自行安装，其他基础依赖由安装器准备。升级LightCut时解压到新目录并复用已有数据，保留原草稿。
