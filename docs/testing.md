## 先记录环境

系统及架构、剪映完整版本、安装方式、Python/FFmpeg版本（若本次方案使用）。在公开 Issue 里隐去用户名、绝对私人路径、设备标识和账号信息。无需提交视频、完整草稿或资源缓存。

## Windows 待验收顺序

1. 只读核对应用版本和组件身份；不加载未知 DLL。
2. 用授权测试环境构建基础样片，校验封面、字体、视频、字幕和声音轨道。
3. 编辑器运行时应等待；编辑器自然退出后登记一个新草稿，不覆盖旧工程。
4. 测试者方便时手动打开样片，确认画面与声音。
5. 保存、退出并重开，再核对轨道和参数。
6. 基础流程通过后，另行测试美颜、滤镜、调色等平台专有资源。

本公开仓库不附运行引擎或私人试验包；取得合法测试环境前不要把上述步骤当成可执行安装教程。
